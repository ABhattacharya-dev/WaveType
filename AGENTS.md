# Repository workflow

Read `CONTRIBUTING.md` before changing release versions or committing work.

Future commits require GitHub-verifiable signatures. If signing is not configured, do not create unsigned commits. Check GitHub's verification status after an authorized push; preserve existing published history.

Keep the `0.1.0-beta1.01`, `0.1.0-beta1.02`, … sequence; change the beta series only when the user explicitly requests it. Make focused local commits for completed features and fixes. Do not push unless the user explicitly requests a push. Preserve unrelated user edits.
