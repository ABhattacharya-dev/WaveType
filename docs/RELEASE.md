# Windows x64 releases

The published WaveType 0.1.0-beta.1 is an unsigned public prerelease for Intel/AMD x64 Windows 10/11. It contains the desktop UI and a separate engine, including Python and the fallback Parakeet CLI. The changes in this source tree move model downloads to the app after installation; they are not yet a published signed release. No Python or CUDA Toolkit installation is required from the user.

The source tree targets **0.1.0-beta1.01**. The NSIS wizard includes welcome and privacy/notices pages, shortcut/startup choices, an installation-directory picker, installation progress, and a finish page with launch and developer-page checkboxes. Startup and the developer link are not preselected. The app downloads Parakeet on first launch; Qwen remains optional and disabled until the user enables it. Settings shows disk usage, relevant download controls, verification/repair and model deletion. Previously downloaded Qwen runtimes remain usable offline; Verify / repair creates current verification receipts. Pause, cancel and intentional deletion survive restart.

Install, upgrade and uninstall require exiting WaveType from the tray first. Setup runs an embedded PowerShell file-access/process check from its temporary directory, holds both instance lock files during mutation and uses a Windows session mutex to prevent new beta 1.01 launches. Older builds are checked through their file locks and mapped application files. Retry/Cancel is offered if files are unavailable; no process is force-closed. Silent failure returns exit code 2. This implements the approved simpler alternative to Restart Manager shutdown.

Uninstall offers an unchecked **Also delete all local data** option. Keeping data restores models, partial downloads, settings, dictionary, history and logs on reinstall. Removal is restricted to the canonical `%LOCALAPPDATA%\STTCore`; linked directories are rejected, and custom locations are left alone. Silent uninstall uses `Uninstall.exe /S` to keep data or `Uninstall.exe /S /REMOVE-DATA` to remove it. Application file removal is checked before deleting registration. Data-removal failures return exit code 3 and retain the uninstall entry for retry; details identify the affected path. Earlier beta uninstallers cannot be changed retroactively: the new installer supplies the corrected uninstaller.

## Build

Create an x64 Python 3.12 virtual environment and install requirements-build.txt. Install NSIS 3. Run PowerShell with `powershell -ExecutionPolicy Bypass -File .\build.ps1 -Version 0.1.0-beta1.01` for an unsigned development build. For a release, install Windows SDK SignTool, obtain a publicly trusted code-signing certificate, place its private key outside Git, set `WAVETYPE_SIGN_CERT_THUMBPRINT` to its 40-character certificate thumbprint, and run the same build command with `-Sign`. The build signs the two WaveType-owned executables before generating the manifest, then signs the installer and verifies all three signatures before generating SHA256SUMS.txt. Do not publish an unsigned development build as a SmartScreen fix.

The build uses PyInstaller folders with UPX disabled, version resources and the provided WaveType icon. Raw audio capture does not use NumPy; the engine build excludes NumPy and PyTorch. The metadata script checks the app and engine PE architecture, rejects personal/model data in the bundle, copies dependency notices, creates build-info.json and install-manifest.json, and emits the file-specific uninstaller list. NSIS compiler warnings are errors. Outputs are dist/WaveType-0.1.0-beta1.01-Setup-x64.exe and dist/SHA256SUMS.txt. Neither binaries nor model files are committed to Git.

## Current validation status

Beta 1.01 development validation (29 October 2026): `python -m unittest discover` runs 56 tests, with 55 passing and one symbolic-link test skipped because this account cannot create symbolic links. A separate real Windows junction test passes. Coverage includes interrupted/resumed downloads, hashes, disk-space failures, deletion scope, CPU/GPU runtime deletion, persistent intent/errors, duplicate actions, failed native-library load cleanup, Settings visibility/progress and theme icons, unavailable microphones, maintenance launch gating, locked data and safe removal retries. Ruff undefined/unused-name checks pass. PyInstaller and NSIS compile successfully with warnings treated as errors; x64 and bundle privacy checks pass.

The packaged engine smoke check passes: offline first launch, Settings IPC, deleting both models, CPU/GPU runtime deletion, restart persistence, personal-data preservation and graceful engine shutdown in an isolated temporary data directory. Repeat with `python packaging/smoke_engine.py dist/WaveType/engine/WaveTypeEngine.exe` after building. The installer checksum is recorded in `dist/SHA256SUMS.txt`; Authenticode currently reports `NotSigned`.

Not yet validated in disposable Windows 10/11 accounts or VMs: both full uninstall/reinstall choices; upgrade/uninstall while visible, tray-only, recording, downloading or unresponsive; real loaded Parakeet/Qwen deletion; full online model downloads; packaged UI progress and keyboard navigation; and immediate reinstall after removal. Source Tk tests verify control visibility, focusability and light/dark icon behavior, but do not replace manual packaged UI checks. Do not run destructive uninstall checks against a developer's real data.

No trusted signing certificate is currently available locally. Defender validation has not been performed for these changes, and no antivirus-pass claim is made. A new GitHub release must describe its actual signing and validation status. Installer size and its SHA-256 should be published with the artifact.

## Signing and stable release

Use a publicly trusted code-signing identity, kept outside Git. The `-Sign` build path signs WaveType.exe and engine/WaveTypeEngine.exe with SHA-256 and a trusted timestamp before assembling the installer, then signs the final installer. Preserve upstream signatures and notices. Verify signatures using `signtool verify /pa /v`. Self-signing is not a substitute for a trusted public publisher identity. A new signed file may still show SmartScreen warnings until publisher or file reputation builds.

Before a stable release, validate clean Windows 10/11 systems with no Python or CUDA Toolkit, model-download failure/resume, GPU/CPU paths, microphone permissions, hotkeys, normal-app insertion, selected shortcuts/startup, upgrade and uninstall. Scan the exact final artifacts with current Defender protection and capture runtime network traffic to verify the documented privacy behavior. Never require users to disable antivirus or add exclusions. Investigate any detection; submit a confirmed false positive to Microsoft as a software developer.

Publish immutable artifacts, their checksums, source tag, version and honest validation status. The current app opens the GitHub releases page on demand; automatic update installation is not implemented. A future updater must verify the installer hash and trusted Authenticode signature before launching it.

## Windows Settings integration

The installer registers `EstimatedSize` in KiB from the installed application folder, including the uninstaller. Installing or upgrading with this build supplies the previously missing app-size entry; Windows may cache its display until Settings is reopened. Downloaded models and personal data are separate from the application estimate; per-model usage is available in WaveType Settings. The existing publisher, display version, startup registration and uninstall entry remain available.

The size-registration path was exercised using an isolated NSIS executable and temporary registry key: a 5 KiB fixture produced an `EstimatedSize` DWORD of 5, and the test key was removed. Rendering the value in Windows Settings for a real installation remains a manual check after installing this build.

The full Windows Advanced options page (including OS-managed reset, repair, background permissions and usage details) is intentionally deferred. WaveType remains an unpackaged NSIS desktop application; adding MSIX integration would change packaging and data lifecycle. See [Microsoft’s MSIX reset and repair guidance](https://learn.microsoft.com/en-us/windows/msix/desktop/managing-your-msix-reset-and-repair). Model repair/deletion and the optional uninstall data removal remain available within the existing app and installer.
