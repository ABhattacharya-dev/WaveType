# Windows x64 releases

WaveType **0.1.0-beta1.04 (first-run and Notepad fixes)** is an unsigned Windows x64 prerelease, following `0.1.0-beta1.03.1`. It includes Python, the desktop app and engine; no separate Python or CUDA Toolkit installation is needed. [Download the release](https://github.com/ABhattacharya-dev/WaveType/releases/tag/v0.1.0-beta1.04) or read the [short changes](releases/0.1.0-beta1.04.md).

SmartScreen warnings may occur. GitHub's Verified badge on the source commits does not sign the Windows installer or establish publisher reputation. This release does not fix SmartScreen reputation. Keep Windows security protections enabled.

Beta 1.04 includes a verified Parakeet runtime DLL, uses Windows certificate trust for downloads, and fixes corrupted Notepad insertion. Beta 1.03.1 repaired the express update handoff and recognizes beta 1 patch versions for update checks. Beta 1.03 added an off-by-default Assistant voice mode on Ctrl+Shift+Win, with a lime waveform and local transcription. Assistant speech does not insert text or use Smart cleanup; it appears in local History with an **Assistant** source badge. The Shortcuts page saves app, folder, and website nicknames, validates targets, and shows Save only for changed rows. Complete `open <nickname>` commands launch saved apps, open saved folders in Explorer, or open saved websites in the Windows default browser. Missing local targets show **Not Found** and Windows launch errors show **Open failed**; website launches do not check remote page loading. The Settings GPU check no longer opens a transient console window. Dictionary save confirmations and warnings remain visible after page redraws.

Manual install, upgrade and uninstall require exiting WaveType from the tray first. An approved in-app update shuts down the app and engine, runs the installer in update-only silent mode, then reopens WaveType. The update-only path requires an existing installation and preserves its location, shortcuts and startup choice. Setup checks file access, holds the instance locks during mutation and uses a session mutex to prevent new launches. Retry/Cancel is offered for blocked manual setup; no process is force-closed. Silent failure returns exit code 2.

Uninstall offers an unchecked **Also delete all local data** option. Keeping data restores models, partial downloads, settings, dictionary, shortcuts, history and logs on reinstall. Removal is restricted to the canonical `%LOCALAPPDATA%\STTCore`; linked directories are rejected, and custom locations are left alone. Silent uninstall uses `Uninstall.exe /S` to keep data or `Uninstall.exe /S /REMOVE-DATA` to remove it. Application file removal is checked before deleting registration. Data-removal failures return exit code 3 and retain the uninstall entry for retry; details identify the affected path. Earlier beta uninstallers cannot be changed retroactively: the new installer supplies the corrected uninstaller.

## Build

Create an x64 Python 3.12 virtual environment and install requirements-build.txt. Install NSIS 3. Run PowerShell with `powershell -ExecutionPolicy Bypass -File .\build.ps1 -Version 0.1.0-beta1.04` for this unsigned prerelease. For a future signed release, install Windows SDK SignTool, obtain a publicly trusted code-signing certificate, place its private key outside Git, set `WAVETYPE_SIGN_CERT_THUMBPRINT` to its 40-character certificate thumbprint, and run the build with `-Sign`. That path signs the two WaveType-owned executables before generating the manifest, then signs the installer and verifies all three signatures before generating SHA256SUMS.txt. Do not present an unsigned build as a SmartScreen fix.

The build uses PyInstaller folders with UPX disabled, version resources and the provided WaveType icon. Raw audio capture does not use NumPy; the engine build excludes NumPy and PyTorch. The metadata script checks the app and engine PE architecture, rejects personal/model data in the bundle, copies dependency notices, creates build-info.json and install-manifest.json, and emits the file-specific uninstaller list. NSIS compiler warnings are errors. The beta 1.04 build produces `dist/WaveType-0.1.0-beta1.04-Setup-x64.exe` and `dist/SHA256SUMS.txt`. Neither binaries nor model files are committed to Git.

The beta 1.04 build fetches the pinned parakeet.cpp runtime ZIP if its verified local cache is absent, checks the archive and DLL hashes, and bundles the DLL with the engine. The ZIP, DLL, model weights and installer remain outside Git. The runtime dependency `truststore` uses Windows CryptoAPI for certificate-chain validation during model and optional runtime downloads. Run `python packaging/smoke_engine.py dist/WaveType/engine/WaveTypeEngine.exe --model <path-to-verified-redux-q8_0.gguf>` for the offline missing-DLL case and `python packaging/smoke_tls_failure.py dist/WaveType/engine/WaveTypeEngine.exe --openssl <path-to-openssl.exe>` for an isolated untrusted-certificate check.

## Signing and stable release

Use a publicly trusted code-signing identity, kept outside Git. The `-Sign` build path signs WaveType.exe and engine/WaveTypeEngine.exe with SHA-256 and a trusted timestamp before assembling the installer, then signs the final installer. Preserve upstream signatures and notices. Verify signatures using `signtool verify /pa /v`. Self-signing is not a substitute for a trusted public publisher identity. A new signed file may still show SmartScreen warnings until publisher or file reputation builds.

Before a stable release, validate clean Windows 10/11 systems with no Python or CUDA Toolkit, model-download failure/resume, GPU/CPU paths, microphone permissions, hotkeys, normal-app insertion, selected shortcuts/startup, upgrade and uninstall. Scan the exact final artifacts with current Defender protection and capture runtime network traffic to verify the documented privacy behavior. Never require users to disable antivirus or add exclusions. Investigate any detection; submit a confirmed false positive to Microsoft as a software developer.

Publish immutable artifacts, their checksums, source tag, version and honest validation status. This version checks GitHub Releases and verifies the selected installer's SHA-256 against the release checksum before launching it. The installer is unsigned; SHA-256 verification and a GitHub Verified commit are not Authenticode publisher verification. Add signature verification when a trusted signing certificate becomes available.

## Windows Settings integration

The installer registers `EstimatedSize` in KiB from the installed application folder, including the uninstaller. Installing or upgrading with this build supplies the previously missing app-size entry; Windows may cache its display until Settings is reopened. Downloaded models and personal data are separate from the application estimate; per-model usage is available in WaveType Settings. The existing publisher, display version, startup registration and uninstall entry remain available.

The size-registration path was exercised using an isolated NSIS executable and temporary registry key: a 5 KiB fixture produced an `EstimatedSize` DWORD of 5, and the test key was removed. Rendering the value in Windows Settings for a real installation remains a manual check after installing this build.

The full Windows Advanced options page (including OS-managed reset, repair, background permissions and usage details) is intentionally deferred. WaveType remains an unpackaged NSIS desktop application; adding MSIX integration would change packaging and data lifecycle. See [Microsoft’s MSIX reset and repair guidance](https://learn.microsoft.com/en-us/windows/msix/desktop/managing-your-msix-reset-and-repair). Model repair/deletion and the optional uninstall data removal remain available within the existing app and installer.
