# WaveType 0.1.0-beta1.01 — Windows x64 preview

Changes since **0.1.0-beta.1**:

- Installation completes without downloading models.
- Parakeet downloads on first launch; Qwen stays optional.
- Settings adds download, pause/resume, cancel, and verify/repair controls.
- Model downloads show progress and disk usage.
- Delete either model independently, including its downloaded runtimes.
- Qwen deletion removes CPU/GPU runtimes and disables Smart cleanup.
- Pause, cancel, and model deletion choices survive restart.
- Interrupted downloads resume; corrupt files can be repaired.
- Settings stays accessible when a model or microphone is unavailable.
- Uninstall offers optional removal of all local data; keeping data is the default.
- Setup checks that WaveType has exited before upgrade or uninstall.
- Failed removals retain the uninstall entry for retry.
- Windows Installed apps receives an application-size entry.
- Improved engine shutdown and updated privacy, About, and licence notices.
- Includes the project's MIT licence and current contribution/accessibility documentation.

**SmartScreen:** This installer is unsigned and warnings still occur. The maintainer reports that “Run anyway” is now available on their machine. This is not a SmartScreen fix or a guarantee for other PCs. Trusted signing is still pending. Keep Windows security protections enabled.

**Upgrade:** Exit WaveType from the tray, then run the new installer. Old uninstallers cannot be changed retroactively; installing this version supplies the new uninstaller. The optional Windows Advanced options page is not implemented.

**Validation:** 55 automated tests passed; one symbolic-link test was skipped. The packaged-engine offline/deletion/restart smoke test and isolated installed-size registration test passed. Clean Windows 10/11 install/uninstall testing, full packaged UI validation and Defender scanning remain pending. See [validation details](../RELEASE.md).

Download `WaveType-0.1.0-beta1.01-Setup-x64.exe` and verify it against the attached `SHA256SUMS.txt`. Models download separately. Both installer and matching source are available from the [release page](https://github.com/ABhattacharya-dev/WaveType/releases/tag/v0.1.0-beta1.01).
