# WaveType 0.1.0-beta1.02 — Windows x64 preview

Changes since **0.1.0-beta1.01**:

- Settings can check GitHub Releases for a newer beta 1 version. Automatic checks and downloads are optional and off by default.
- App update downloads show progress and support Pause, Resume, and Cancel. The installer must match the release SHA-256 checksum before installation is offered.
- After approval, WaveType closes, installs the update while preserving the installation location and shortcut/startup choices, then reopens.
- The desktop event connection no longer times out after 180 idle seconds, addressing dictation controls and model repair becoming unresponsive after sleep.

**Upgrade:** Users of beta 1.01 need to download and run beta 1.02 manually. Once beta 1.02 is installed, future beta 1 updates can be checked from Settings. Exit WaveType from the tray before a manual setup run. In-app updates close it after approval. Models, settings, dictionary, and history are kept.

**Signing:** The source commits are signed and verified by GitHub. The Windows installer is **unsigned**; this release does not fix SmartScreen reputation. Keep Windows security protections enabled. Verify the downloaded installer against the attached `SHA256SUMS.txt`.

**Validation:** Source tests, packaged engine smoke checks, installer build, release checksum, and update-only installer guard are checked. A real long-sleep cycle, a full in-app upgrade, clean Windows 10/11 installations, and Defender scanning have not yet been completed. See [release validation details](../RELEASE.md).

Download `WaveType-0.1.0-beta1.02-Setup-x64.exe` and `SHA256SUMS.txt` from the [beta 1.02 release](https://github.com/ABhattacharya-dev/WaveType/releases/tag/v0.1.0-beta1.02).
