# WaveType 0.1.0-beta1.04 (first-run and Notepad fixes) — Windows x64 preview

Changes since **0.1.0-beta1.03.1**:

- Bundle the pinned, SHA-256-verified Parakeet runtime DLL with the installer. If model weights are already valid but the DLL is missing, **Verify / repair** restores it offline.
- Use Windows certificate-chain validation for model and optional runtime downloads. TLS verification and pinned file hashes remain required. Setup now distinguishes model, runtime, and download failures and offers a clearer retry path.
- Fix missing and repeated characters in Windows 11 Notepad. Notepad insertion uses a brief clipboard paste, restores supported clipboard formats, and excludes the temporary text from Windows clipboard history and cloud sync. If a clipboard format cannot be preserved, the result remains in WaveType History for manual insertion. Other apps keep Unicode key input.

**Upgrade:** Beta1.03.1 can check for and install this version in Settings after approval. To run the installer manually, exit WaveType from the tray first. Beta1.02 and beta1.03 need a manual installer because their published update handoff cannot finish an express update. Normal setup keeps local models, settings, dictionary, shortcuts, and History.

**Signing:** The source commits and release tag use a GitHub-registered signing identity. The Windows installer is **unsigned** because no trusted Windows code-signing certificate is available. GitHub's Verified badge does not sign the installer or remove SmartScreen warnings. Keep Windows security protections enabled and compare the download with `SHA256SUMS.txt`.

**Validation:** The Python 3.12 suite passed 96 tests, with one symbolic-link test skipped. On Windows 11 Pro x64, the packaged engine passed offline startup and missing-DLL recovery checks; an untrusted certificate was rejected. Live Notepad tests matched the final text for ordinary dictation with Unicode, name/email snippets, and a 348-character passage while restoring the prior clipboard formats and bytes. A clean Windows 10/11 installation, an installed-app end-to-end update and dictation, Windows 10 Notepad, and Defender scanning were not available for validation. See [release validation details](../RELEASE.md).

Download the installer and `SHA256SUMS.txt` from the [beta 1.04 release](https://github.com/ABhattacharya-dev/WaveType/releases/tag/v0.1.0-beta1.04).
