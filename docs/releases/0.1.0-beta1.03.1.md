# WaveType 0.1.0-beta1.03.1 (Auto update fix) — Windows x64 preview

Changes since **0.1.0-beta1.03**:

- Fix the express update handoff. PowerShell now runs the update helper without `DETACHED_PROCESS`, so it can install the verified download and reopen WaveType after approval.
- Hash the installer using the Windows .NET runtime instead of a PowerShell command that may be unavailable in a windowless launch.
- Recognize beta 1 patch versions such as `.03.1` when checking future releases. The beta1.03 Assistant and shortcut features are unchanged.

**Upgrade from beta1.02 or beta1.03:** Exit WaveType from the tray and run `WaveType-0.1.0-beta1.03.1-Setup-x64.exe` manually. Those published versions cannot discover `.03.1`, and their express update handoff is broken. The normal installer keeps local models, settings, dictionary, shortcuts, and history. Once beta1.03.1 is installed, its updater can check later beta 1 releases.

**Signing:** The source commits and release tag are signed with a GitHub registered identity. The Windows installer is **unsigned** because no trusted code signing certificate is available. GitHub's Verified badge does not sign the installer or remove SmartScreen warnings. Keep Windows security protections enabled and compare the download with `SHA256SUMS.txt`.

**Validation:** See [release validation details](../RELEASE.md) for the checks actually completed and remaining platform limits.

Download the installer and `SHA256SUMS.txt` from the [beta 1.03.1 release](https://github.com/ABhattacharya-dev/WaveType/releases/tag/v0.1.0-beta1.03.1).
