# WaveType 0.1.0-beta1.03 (Assistant) — Windows x64 preview

Changes since **0.1.0-beta1.02**:

- Enable Assistant in Settings, then hold or tap **Ctrl+Shift+Win** to speak a command. The Assistant pill uses a lime waveform. **Ctrl+Win** continues to control dictation; either hotkey can finish a locked Assistant capture.
- Add app, folder, and website shortcuts with unique nicknames on the new **Shortcuts** page. Say **“open <nickname>”** as the complete command. Apps open through Windows, folders open in Explorer, and websites open in the default browser. A missing local target shows **Not Found** in the pill; a rejected launch shows **Open failed**.
- Shortcut editing validates pasted paths and URLs and shows Save only after a change. Dictionary notices remain visible. The Settings GPU check no longer flashes a console window.
- Assistant commands appear in local History with **Assistant** as their source. Assistant speech is not inserted into another app and does not use Smart cleanup.

**Upgrade:** Beta 1.02 users can use Settings to check for beta 1.03, download the installer, and approve the update. A manual installer run requires exiting WaveType from the tray first. Existing models, settings, dictionary, shortcuts, and history are kept.

**Signing:** The source commits and release tag are signed with a GitHub registered identity. The Windows installer is **unsigned** because no trusted code signing certificate is available. GitHub's Verified badge does not sign the installer or remove SmartScreen warnings. Keep Windows security protections enabled and compare the download with `SHA256SUMS.txt`.

**Validation:** The Python 3.12 source suite passes 81 tests, with one symbolic-link test skipped on this account. The Windows x64 installer and packaged engine were checked on the development machine. Clean Windows 10/11 installation, a full installed upgrade, keyboard accessibility, Defender scanning, and remote website loading were not validated. See [release validation details](../RELEASE.md).

Download `WaveType-0.1.0-beta1.03-Setup-x64.exe` and `SHA256SUMS.txt` from the [beta 1.03 release](https://github.com/ABhattacharya-dev/WaveType/releases/tag/v0.1.0-beta1.03).
